# OpenSoko

Freeware Sokoban inspired browser game.

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev      # start dev server
npm test         # unit tests
npm run lint     # eslint
npm run build    # typecheck + production build into dist/
```

## Tech

TypeScript, Vite, Canvas 2D, Vitest. Deployed to GitHub Pages via GitHub Actions.
